# Mindora Puzzle App

A Flutter starter app inspired by the supplied visual reference, redesigned with a unique dark neon/glass style.

## Included
- Home dashboard
- Daily Challenge card
- Coins saved locally with SharedPreferences
- 5 mini games:
  1. Color Flow
  2. Number Merge
  3. Block Drop
  4. Sort Puzzle
  5. Mini Sudoku
- Offline-first gameplay
- Responsive Flutter UI

## Run
1. Install Flutter.
2. Run `flutter pub get`
3. Run `flutter run`

For Android release:
`flutter build apk --release`
or
`flutter build appbundle --release`

This is a functional starter/MVP. Game mechanics can be expanded with real level generation, animations, sounds, ads, analytics, and store assets.
